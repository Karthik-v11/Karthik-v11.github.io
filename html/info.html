About me

I ship things that move data in real time, render in 3D, and fit in a pocket.

I'm a software engineer in Bengaluru who builds mobile apps, real-time dashboards, and browser-based 3D experiences — the kind of software that runs on a shop floor, surfaces live machine data, and ships to real users on iOS and Android.

I focus on making complex systems feel simple: offline-first sync patterns, high-frequency data streams rendered without dropped frames, and UI that operators can read at a glance. Every project I ship teaches me something about performance, reliability, or how people actually use the tools they're given.

On the side, I'm building a real-time multiplayer chess variant with WebSocket sync and a custom engine — part learning project, part obsession. I've also been experimenting with WebGL shaders for a browser-based audio visualizer, and I occasionally write about engineering decisions on Medium.

How I like to work

  • Ship something real early, then sharpen it
  • Fewer moving parts beats clever architecture
  • Performance is a feature, not a phase
  • Write it down — future me is a stranger
  • Animation should carry meaning, not decoration
