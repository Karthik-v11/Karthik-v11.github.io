IMTEX 2025 WebVR
AmiT / AceMicromatic MIT - Jan' 25
The Vision
Industrial exhibitions like IMTEX are massive, but even the biggest booths have physical limits. My goal was to break those boundaries by creating a high-performance 3D Virtual Showroom that brings Ace Micromatic's entire 30+ machine catalog to anyone with a browser.

Built on Next.js 14 and React Three Fiber, this wasn't just about showing images—it was about creating an immersive, interactive digital floor. I engineered a seamless navigation system using GSAP, allowing users to move through a futuristic showroom and interact with 1:1 scale machine models. Each station provides a deep dive into technical specs, PDF brochures, and image galleries, bridging the gap between physical hardware and digital exploration.

This project pushed me to master 3D performance optimization, managing dozens of detailed GLB models on mobile devices while maintaining a premium, high-fidelity aesthetic. It transformed the exhibition experience into a persistent, global sales tool that lives on long after the physical event.
