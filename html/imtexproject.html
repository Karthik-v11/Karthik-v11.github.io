IMTEX 2025 WebVR
AmiT / AceMicromatic MIT - Jan' 25
Sections
Overview Highlights
Making a 3D catalogue run smoothly on a mid-range phone.
Context: AmiT / AceMicromatic MIT needed its 30+ machine catalogue to outlive a physical trade-show booth. Before this, prospects only saw static spec sheets — there was no way to walk around a machine at 1:1 scale or pull its brochure without a salesperson on site.

My role: I owned the entire implementation — 3D scene assembly, performance optimization, Next.js routing, and GSAP interactions — while a 3D artist created the GLB machine models and textures.

Approach: I built the IMTEX 2025 WebVR experience on Next.js 14 and React Three Fiber (R3F). I engineered a GSAP-driven navigation system for moving through the virtual showroom and interacting with 1:1 scale machine models. Each station includes technical specs, PDF brochures, and image galleries. The core challenge was 3D performance on a 50 MB model catalog: I used draw-call batching, GLB compression via Draco, texture compression, and LOD (level-of-detail) switching so machines swap to lower-detail versions past a distance — keeping a 3-year-old phone rendering at stable 30 fps.

Key decision — fidelity vs. mobile performance: The showroom had to run on phones, not just demo hardware, so I optimized for a playable frame rate over maximum polygon fidelity: a machine looks photo-real up close, then fades to a lighter LOD as you step back. The trade-off is that the highest-detail model can't run on the cheapest device — but the experience never drops below a usable frame rate. I also chose Next.js over a leaner Three.js app because the project needed dynamic routing for 30+ machine detail pages, SSR for SEO, and a CMS-backed spec database — at the cost of a heavier initial bundle (~2.5 MB gzip), mitigated by route-based code splitting and dynamic model loading.

Impact: 30+ machine models, each with spec panels and PDF brochures, running at a stable 30 fps in any browser on mid-range phones and laptops — turning a physical exhibition booth into a persistent, global sales tool.
